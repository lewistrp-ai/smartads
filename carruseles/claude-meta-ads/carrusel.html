Paso 01

Dale contexto

Prompt para Claude

Actúa como media buyer experto en Meta Ads.

Mi negocio: [qué vendes]
Cliente ideal: [edad, ciudad, su dolor]
Oferta: [precio, garantía, bono]
Objetivo: [mensajes a WhatsApp / ventas]

Si te falta información, pregúntame antes de escribir.

Entre más contexto le das, menos genérico suena.

Paso 02

Pide ángulos, no copies

Prompt para Claude

Dame 10 ángulos de venta diferentes: dolor, deseo, objeción, comparación y prueba social.

Para cada uno escribe un gancho de máximo 8 palabras.

Un buen ángulo vale más que un copy bonito. Escoge los 3 que más te pegan.

Paso 03

Copies listos para pegar

Prompt para Claude

Con estos 3 ángulos escribe 3 variaciones de cada uno:

• Texto principal (gancho en los primeros 125 caracteres)
• Título (máx. 40 caracteres)
• Descripción (máx. 30 caracteres)

Tono cercano, español de Colombia.

Así salen con el formato exacto que pide el Administrador de anuncios.

Paso 04

Ideas para el creativo

Prompt para Claude

Para cada ángulo dame:

1. Un guion de reel de 15 segundos: gancho (0-3 s), desarrollo y llamado a la acción.
2. Una idea de imagen estática con el texto exacto que va encima.

Grabas tú, pero ya sabes qué decir y qué mostrar.
